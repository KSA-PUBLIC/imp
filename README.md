# K-CSI × IMP | 지역 지속가능성·조직 임팩트 통합 분석 플랫폼

한국표준협회 공공혁신센터의 **지역 지속가능성(K-CSI)·조직 임팩트(IMP) 통합 분석 플랫폼**입니다. 72개 셀을 공통 기준으로 지역 분석, 조직 진단, 「1118 이슈별 임팩트 포트폴리오」(148쪽)의 실행모델을 연결합니다.

> **기준일:** 2026-11-18
> **디자인:** 딥블루 + 밝은 중립색, Pretendard
> **실행 방식:** 별도 빌드가 없는 정적 HTML 페이지

## 1. 이번 버전에서 바뀐 점

| 구분 | 내용 |
|---|---|
| 지역 결과 표시 | K-CSI 순위·점수·등급 글자를 모두 빼고 다섯 단계 색의 농도로만 표시(파일 안의 원점수·순위도 삭제) |
| 대문 72셀 | 평면 격자를 비스듬히 눕힌 입체 블록으로 표현(높이 = 셀의 K-CSI 지표 수 단계) |
| 지역 지도 | 지도 영역을 넓히고 확대·축소·이동 기능을 추가 |
| 문안 | 포트폴리오 본문의 낱말 중간 띄어쓰기 1,590개 항목 정리, 화면 표기 통일 |
| 색 | 파란 계열의 채도와 대비 보강(톤과 배치는 유지) |
| 화면 이동 | 단계 표시, 아래 고정 이동 막대, 누를 수 있는 카드 표시를 통일 |

조직 분류, 포트폴리오의 내용·수치, 화면 주소(`#...`)는 바꾸지 않았습니다. K-CSI 지역 결과는 `index.html` 안에 5단계 값만 남기고 원점수와 순위는 삭제했습니다. 색이 진할수록 전국 비교에서 상대적으로 높은 수준입니다.

### 1-1. 지역 지속가능성 인터랙티브 지도

- **크기:** 지도 칸을 화면의 약 3분의 2 너비, 화면 높이의 약 74%로 키웠습니다. `넓게` 버튼을 누르면 지도가 화면 전체 너비로 펼쳐집니다.
- **확대·축소:** 오른쪽 위 `+` `−` `전체` 버튼, 마우스 휠, 두 손가락 벌리기, 빈 곳 더블클릭, 키보드 `+` `−` `0`. 최대 14배까지 확대됩니다.
- **이동:** 확대한 상태에서 끌어서 옮깁니다. 끌다가 손을 떼도 지역이 눌리지 않습니다.
- **시·도 선택 연동:** 오른쪽에서 시·도를 고르면 지도가 그 시·도로 자동 확대됩니다.
- **지역 이름:** 1.6배 이상 확대하면 칸 크기가 충분한 시·군·구부터 이름이 나타납니다.
- **안내 말풍선:** 마우스를 올리면 지역 이름이 표시됩니다.
- **색:** K-CSI 종합 수준을 다섯 단계 파랑의 농도로 구분합니다(글자·숫자 표기 없음). 회색은 분석 대상이 아닌 지역입니다.
- **휴대폰:** 기본 배율에서는 한 손가락으로 화면이 스크롤되고, 확대한 뒤에는 지도가 움직입니다.

### 1-2. 문안 퇴고

- **포트폴리오 본문:** 원문 표에서 줄이 바뀌며 낱말 중간에 들어간 공백을 정리했습니다(예: `갈 등 감소` → `갈등 감소`, `플 랫폼` → `플랫폼`). 3,124개 항목 가운데 1,590개 항목이 바뀌었고, **공백 외의 글자와 수치는 한 글자도 바뀌지 않았음을 자동 대조로 확인**했습니다. `portfolio_data.json`에도 같은 내용을 반영했습니다.
- **화면 표기:** `시군구`·`시도`를 `시·군·구`·`시·도`로 통일하고 지도 안내 문구를 다듬었습니다.
- **한계:** 띄어쓰기 정리는 문서 안의 낱말 빈도를 기준으로 자동 처리한 뒤 목록을 훑어 예외를 손봤습니다. 드물게 쓰인 낱말은 끊긴 채 남아 있을 수 있습니다.

### 1-3. 색과 화면 이동

- 파란 계열 색을 밝기는 유지한 채 채도만 일괄로 올렸습니다. 기준 색은 딥네이비 `#0E3462`, 주요 파랑 `#1557A8`, 보조 파랑 `#3F86D6`입니다.
- 단계 표시: 지나온 단계는 체크, 현재 단계는 진한 파랑 채움, 남은 단계는 흰 바탕입니다.
- 아래 고정 이동 막대: 왼쪽 "이전", 가운데 현재 위치, 오른쪽 "다음". 무엇을 골라야 넘어가는 화면에는 안내 문구가 나옵니다.
- 누를 수 있는 카드에는 오른쪽 위에 화살표 원이 붙습니다.
- 키보드 ← → 로 이전·다음 화면으로 넘어갑니다(입력 중에는 동작하지 않음).

## 4. 포트폴리오 원천자료와 적용 범위

원문은 **「1118 이슈별 임팩트 포트폴리오」(2026-11-18 제공, 148쪽)**이며 4개 영역, 12개 이슈로 구성됩니다.

| Part | 분야 | 수록 이슈 |
|---|---|---|
| 1 | 공동체 기반 및 시민 주권 | 01 거버넌스·권한부여·참여 / 03 공생·상호의존·상호성 / 11 문화·공동체 정체성 |
| 2 | 경제 활력 및 혁신 성장 | 12 혁신·창의성·연구 / 04 경제·생산과 소비 / 02 교육 및 역량 구축 |
| 3 | 삶의 질 및 포용적 안전망 | 06 공동체 건강과 관리 / 05 생활 및 근로 환경 / 07 안전 및 보안 |
| 4 | 물리적·생태적 지속가능 토대 | 08 공동체 인프라 / 09 이동성 / 10 생물다양성·생태계 |

수록 셀마다 대도시 2개, 중소도시 2개, 농어촌 2개의 실행모델이 있고, 모델마다 공유 임팩트, 공공 역할, 민간 역할, 사회연대경제의 수행 역할, 성과 책임, KPI, 협력 방식이 연결됩니다.

**중요:** 분류는 12 × 6 = 72셀이지만 원문에서 독립된 실행모델을 확인할 수 있는 셀은 **71개**입니다. **이슈 11(문화·공동체 정체성) × 목표 6(환경 보전 및 개선)**은 원문에서 확인하지 못해 임의로 작성하지 않고 화면에 **원문 미수록**으로 표시했습니다.

## 5. 해석 및 공개 주의사항

1. **실행모델과 KPI는 실적이 아닙니다.** 제안된 실행 방향과 목표치이며, 특정 조직이나 지자체가 시행하거나 달성했다는 뜻이 아닙니다.
2. **X·Y·Z 등은 미확정 변수입니다.** 사업계획과 통계·증빙을 검토한 뒤 목표를 확정해야 합니다.
3. **ISO 37101은 분류의 준거입니다.** 실행모델과 KPI가 ISO 표준에 규정된 내용이나 실측 검증 결과라는 뜻이 아닙니다.
4. **K-CSI의 지역 결과는 잠정 결과입니다.** 심의·검증이 끝나기 전에는 공식 평가로 단정하지 마세요. 화면에는 점수·순위 없이 색의 농도만 표시됩니다.
5. **조직 참고사례 가운데 일부는 검증 전입니다.** 수록 자체가 한국표준협회의 인증이나 권고를 뜻하지 않습니다.
6. **포트폴리오는 PDF의 텍스트·표 추출을 바탕으로 구조화했습니다.** 이번에 띄어쓰기를 정리했지만, 외부 공개나 계약·제안서 인용 전에는 원문과 문장·수치를 대조해 주세요.
7. **지역 우선 검토는 자동 매칭이나 추천 확정이 아닙니다.** 실제 대상지, 예산, 법·제도, 수행 주체의 역량과 증빙을 검토해 결정해야 합니다.

## 6. 운영 기술 참고

- UI: 브라우저 기반 HTML/CSS/JavaScript
- 폰트: Pretendard, 외부 CDN 연결
- 지리 경계: 원격 `sig.geojson`(https://github.com/KnellBalm/kr-admin-geojson, 국가공간정보포털 2023-07-29 배포본 가공). 인터넷이 막히면 시·도 위치 안내도와 지역 목록으로 대체되며, 이때도 확대·축소는 동작합니다.
- 행정구역 개편으로 경계와 226개 분석 단위가 일치하지 않을 수 있습니다. 세종·제주 등 K-CSI 데이터가 없는 지역은 회색으로 표시되고 눌리지 않습니다.
- 장기 운영 시에는 경계 GeoJSON을 프로젝트에 함께 두고 JS의 `GEO_ENDPOINTS`를 로컬 경로로 바꾸는 것을 권장합니다.
- 이번 변경 위치: `<style>` 끝의 "선명도 보강 + 화면 이동 정리", "지역 지도" 블록과 `<script>`의 `geoZoom`, 끝의 "화면 이동 정리" 블록.

## 7. 검증 기록

- JavaScript 문법 통과, 747개 화면 주소를 차례로 열어 페이지 오류 없음(1440px)
- 지도: 버튼·휠 확대, 끌어서 이동, 시·도 선택 시 자동 확대, 확대 상태에서 지역 클릭 이동, `넓게` 전환 확인
- 실제 시·군·구 경계(GeoJSON)를 내려받아 정밀 지도 상태에서 확인
- 모바일(390px): 가로 넘침 없음
- 포트폴리오: 3,124개 항목 전후 대조에서 공백 외 변경 0건

**확인 제한:** 검증 환경에서 Pretendard CDN이 차단되어 화면 확인은 대체 글꼴로 했습니다. 두 손가락 확대는 실제 터치 기기에서 확인하지 못했습니다. 배포 후 운영 환경에서 확인해 주세요.
