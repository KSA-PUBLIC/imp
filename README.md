# K-CSI × IMP | 이슈별 임팩트 포트폴리오 통합 고도화본

한국표준협회 공공혁신센터의 **지역 지속가능성·조직 임팩트 통합 분석 플랫폼**에 「1118 이슈별 임팩트 포트폴리오」(148쪽)를 구조화하여 연결한 웹페이지입니다.

> **기준일:** 2026-11-18  
> **디자인:** 기존 딥블루 + 밝은 중립색, Pretendard  
> **실행 방식:** 별도 빌드 없는 정적 HTML 페이지

## 1. 이번 버전에서 강화된 기능

| 구성 | 기능 |
|---|---|
| K-CSI 지역 진단 | 기존 226개 시·군·구 K-CSI 지표·등급·매트릭스 유지 |
| IMP 조직 진단 | 기존 조직별 핵심 셀, IMP 차원, 임팩트 창출 체계 및 결과지 유지 |
| **임팩트 포트폴리오** | **71개 수록 셀 및 426개 지역 유형별 실행모델** 제공 |
| 임팩트 포트폴리오 탐색 | 12대 이슈·6대 목표·지역 유형(대도시/중소도시/농어촌) 필터, 키워드 검색 |
| 실행모델 상세 | 공유 임팩트, 사회연대경제의 성과 책임, 공공·민간·사회연대경제 역할, 성과관리 지표, 협력 방식 |
| 72셀 매트릭스 연결 | 셀 분석 페이지마다 해당 임팩트 실행모델 바로가기 제공 |
| 조직별 분석 연계 | 조직의 선택/핵심 셀에 맞는 포트폴리오 참고안 바로가기 |
| 지역 분석 연계 | 상대적으로 개선 여지가 큰 셀에 대응하는 **우선 검토용** 실행모델 접근 |
| 지도 | 기존 지자체 지도 탐색 및 지역 링크 유지 |

기존 분석 지표, 순위, 조직 분류 및 계산 JavaScript 데이터는 유지하고, **자료 탐색·전략 구상 기능**을 별도의 화면으로 확장했습니다.

## 2. 파일 구성과 배포

```text
index.html           실제 웹사이트 (자료·스타일·JavaScript 포함)
README.md            배포 및 데이터 이용 안내
og.png               기존 블루톤의 소셜 링크 미리보기 이미지
portfolio_data.json  원문에서 정리한 구조화 데이터(보존·확인·후속 편집용)
```

네 파일을 GitHub 또는 Vercel 프로젝트의 **최상위 폴더**에 함께 업로드합니다. 웹페이지 자체는 `index.html`만으로 포트폴리오 기능을 실행할 수 있으며, `portfolio_data.json`은 자료 관리용 별도 사본입니다. **외부 폰트 또는 지도 로딩을 제외하면 포트폴리오의 탐색·상세 페이지는 인터넷 연결 없이 실행됩니다.**

## 3. 포트폴리오 원천자료와 적용 범위

자료 원문: **「1118 이슈별 임팩트 포트폴리오」(2026-11-18 제공, 148쪽)**. 원문에는 다음 **4개 영역, 12개 이슈**가 수록되어 있습니다.

| Part | 분야 | 수록 이슈 |
|---|---|---|
| 1 | 공동체 기반 및 시민 주권 | 01 거버넌스·권한부여·참여 / 03 공생·상호의존·상호성 / 11 문화·공동체 정체성 |
| 2 | 경제 활력 및 혁신 성장 | 12 혁신·창의성·연구 / 04 경제·생산과 소비 / 02 교육 및 역량 구축 |
| 3 | 삶의 질 및 포용적 안전망 | 06 공동체 건강과 관리 / 05 생활 및 근로 환경 / 07 안전 및 보안 |
| 4 | 물리적·생태적 지속가능 토대 | 08 공동체 인프라 / 09 이동성 / 10 생물다양성·생태계 |

각 수록 셀은 **6가지 지역 유형별 모델**을 갖습니다: 대도시 2개, 중소도시 2개, 농어촌 2개. 각 모델에는 공유 임팩트, 공공 역할, 민간 역할, 사회연대경제의 수행 역할, 성과 책임, KPI, 협력 방식이 연결됩니다.

**중요:** 기존 분석 분류는 12 × 6 = **72셀**이지만, 업로드된 148쪽 원문에서 독립된 실행모델 섹션을 확인할 수 있는 셀은 **71개**입니다. 특히 **이슈 11(문화·공동체 정체성) × 목표 6(환경 보전 및 개선)**의 독립된 상세 모델을 원문에서 확인하지 못했습니다. 이 셀의 자료를 임의 작성하지 않고, 화면에도 **원문 미수록**으로 표시했습니다.

## 4. 해석 및 공개 주의사항

1. **실행모델과 KPI는 실적이 아닙니다.** 문서에 포함된 수치·계획과 시나리오는 제안된 실행 방향·목표치이며, 해당 조직이나 지자체가 이를 시행하거나 달성했다고 볼 수 없습니다.
2. **X·Y·Z 등은 미확정 변수입니다.** 사업별 사업계획과 통계·증빙 검토 후 목표를 확정해야 합니다.
3. **ISO 37101은 분류의 준거입니다.** 업로드 문서의 지역 유형별 실행모델과 KPI가 ISO 표준 자체에 규정된 ‘공식 정답’이나 실측 검증 결과라는 의미는 아닙니다.
4. **K-CSI의 지역 점수·순위는 기존의 잠정 결과**입니다. 심의·검증 완료 전 공식 평가로 단정하지 마세요.
5. **기존 조직 참고사례 가운데 일부는 검증 전**입니다. 이 사례에 대한 수록 자체가 한국표준협회의 인증 또는 권고를 의미하지 않습니다.
6. 포트폴리오는 `PyMuPDF`의 텍스트·표 추출을 기반으로 구조화했습니다. 표 안에서 줄바꿈된 어절의 띄어쓰기를 일부 정리했으나, **외부 정식 공개나 계약·제안서 인용 전에는 원문과 문장·수치 대조 검수**를 권장합니다.
7. **지역 우선 검토는 자동 매칭/추천 확정이 아닙니다.** 실제 사업 대상지, 예산, 법·제도, 수행주체 역량과 임팩트 증빙을 검토해 결정해야 합니다.

## 5. 운영 기술 참고

- UI: 브라우저 기반 HTML/CSS/JavaScript
- 폰트: **Pretendard**, 기존과 동일하게 외부 CDN 연결
- 지리 경계: 기존 `sig.geojson` 원격 데이터 경로 사용 (오프라인에서는 대체 지도와 목록 링크)
- 포트폴리오: 전체 구조화 JSON을 `index.html`에 내장하여 추가 네트워크 호출 없이 검색·열람
- 검색: 이슈·목표·지역 유형 선택 및 키워드 필터. 포트폴리오 상세 링크는 URL 해시로 공유 가능
- 데이터: `portfolio_data.json` 파일에는 `cells`(72개 키), 각 `cases`(모델), `sourcePages`(원문 페이지), `status`가 포함됩니다.

## 6. 검증 기록

- 데이터: 72개 분류 키, **71개 문서 수록 셀**, **426개 실행모델**, 모델별 7개 설명 필드 존재 여부 점검
- JavaScript 문법: 통과
- PC(1440px), 태블릿(768px), 모바일(390px)에서 주요 9개 화면 유형: 가로 넘침 및 페이지 JavaScript 예외 없음
- 필터: 이슈→목표 조건 축소 동작 확인
- 상세: 6개 전체 모델, 중소도시 2개 모델 전환 확인
- 누락: 원문 미수록 셀 안내 화면 확인
- 연결: 조직별 분석·72셀·지역 분석에서 포트폴리오 진입 확인

**확인 제한:** 자동화 브라우저의 네트워크 제한으로 외부 Pretendard CDN과 실제 GeoJSON 내려받기·실서비스 배포 상태는 검증하지 못했습니다. 배포 후 운영 환경에서 별도로 확인해 주세요.
