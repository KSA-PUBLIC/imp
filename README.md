# K-CSI × IMP | 전문 문안·용어 정제본

기존 **딥블루 디자인·Pretendard·인터랙티브 지도·72셀/조직·지역 분석 기능을 유지**하면서 사용자 화면의 문구를 정제한 배포본입니다.

## 문안 수정 원칙

- **통일된 어휘**: K-CSI는 ‘지역 지속가능성 분석’, IMP는 ‘조직 임팩트 창출 체계 및 성과 진단’으로 설명합니다.
- **정확한 구분**: 투입(Input) → 활동(Activity) → 산출(Output) → 성과(Outcome) → 장기적 영향(Impact)으로 표기합니다.
- **신중한 해석**: 순위가 낮은 지역은 ‘협력 우선 검토 지역’으로 표현하며, 자동 추천 또는 협력 적합성의 확정으로 안내하지 않습니다.
- **출처와 상태**: 잠정 점수·검증되지 않은 조직 참고 사례·미공개 측정값의 주의 문구를 유지하고 명확히 했습니다.
- **디자인·기능 유지**: CSS, 지역별 데이터, K-CSI 지표·점수·분류 로직, 화면 라우팅은 변경하지 않았습니다.
- **검색·공유**: 제목·소개·OG/Twitter 메타 설명도 동일한 용어로 갱신했습니다.

## 배포 파일

- `index.html` : 웹페이지 전체. Pretendard 웹폰트와 지역 지도는 기존과 같이 외부 CDN/데이터 연결을 이용합니다.
- `og.png` : 기존 브랜드 디자인의 1200×630 공유 미리보기(이미지 디자인 유지).
- `README.md` : 배포 방법과 데이터 제한 사항.

## 기존 데이터·지도의 유의사항

- 정밀 지도는 브라우저에서 `sig.geojson`을 요청합니다: https://github.com/KnellBalm/kr-admin-geojson
- 경계 원자료: 국가공간정보포털(V-World), 2023-07-29 배포본을 가공한 GeoJSON. 원 출처 표기 조건으로 사용 가능
- 새 주소/행정구역 개편 때문에 경계와 226개 K-CSI 분석단위가 일치하지 않을 수 있습니다. 특히 수원시 등 일반구가 있는 시는 여러 개의 경계가 동일 시 진단에 연결될 수 있습니다.
- 경계 파일은 **HTML에 내장된 것이 아니며** 외부 인터넷/CDN이 차단되면 정밀 경계가 표시되지 않습니다. 이 경우 대체 시도 위치 선택과 226개 지역 링크는 정상 작동합니다.
- 정밀 지도에 포함된 세종·제주 등은 K-CSI 226개 지역 데이터에 없는 경우 분석 링크가 비활성화됩니다.
- 일부 조직 프로필과 지역 점수는 잠정·검증 전 데이터이므로 외부 공개 전에 검증이 필요합니다.

## 운영 권고

정식 서비스로 장기간 운영할 경우, 외부 CDN URL 의존을 제거하기 위해 행정구역 경계 GeoJSON을 별도 파일로 프로젝트에 포함하는 것을 권장합니다. 그때는 JS의 `GEO_ENDPOINTS`를 로컬 `/sig.geojson`으로 교체하면 됩니다.

## 선명도 보강과 화면 이동 정리 (2026-11-18)

딥블루 톤과 배치는 그대로 두고 채도·대비와 이동 요소만 손봤습니다. 문안, 지역 데이터, K-CSI 지표·점수·분류 로직, 화면 주소(`#...`), 지도 기능은 바꾸지 않았습니다.

### 색
- 스타일 안의 파란 계열 색(약 650곳)을 밝기는 유지한 채 채도만 일괄로 올렸습니다. 회색·흰색과 파랑이 아닌 색은 그대로입니다.
- 기준 색: 딥네이비 `#0E3462`, 주요 파랑 `#1557A8`, 보조 파랑 `#3F86D6`, 연한 파랑 `#C9E0F8`, 배경 `#F2F6FC`, 본문 글자 `#14283F`.
- 72셀 색 단계: `#D2E5FA` → `#93C0F0` → `#3C86D8` → `#0F4A94`. 단계 사이 차이를 키웠습니다.

### 화면 이동
- **단계 표시**: 지나온 단계는 체크 표시, 현재 단계는 진한 파랑 채움, 남은 단계는 흰 바탕으로 구분합니다. 지나온 단계의 이름이 흰 바탕에 흰 글자로 안 보이던 문제를 고쳤습니다.
- **아래 고정 이동 막대**: 모든 화면 아래에 왼쪽 "이전", 가운데 현재 위치(예: 조직 진단 · 4 / 6 단계), 오른쪽 "다음"을 고정했습니다. 72셀·셀·지역 목록처럼 무엇을 골라야 넘어가는 화면에는 "셀을 눌러 다음으로" 같은 안내가 나옵니다.
- **누를 수 있는 카드**: 조직 카드, 진단 결과 항목, 숫자 카드에 오른쪽 위 화살표 원을 붙이고, 올리면 테두리가 진해지도록 통일했습니다.
- **상단 메뉴와 진단 항목 메뉴**: 현재 위치를 밑줄 대신 채움으로 표시합니다.
- **방향키**: 키보드 ← → 로 이전·다음 화면으로 넘어갑니다(검색창 입력 중에는 동작하지 않음).

### 구현 위치
- `index.html`의 `<style>` 끝 "선명도 보강 + 화면 이동 정리" 블록과 `<script>` 끝 "화면 이동 정리" 블록입니다. 두 블록을 지우면 이동 요소는 이전 상태로 돌아갑니다(일괄 채도 보정은 남습니다).
